


## Anwendung der TOMs auf INF.9

| TOM                         | Maßnahme                                                                            | Umsetzung in INF.9 Mobiler Arbeitsplatz                                                                                                                                         |     |
| --------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
| 1. Zugangskontrolle         | Verwehrung des Zugangs für Unbefugte zu Verarbeitungsanlagen                        | IT-Systeme bei Verlassen des Raums sperren oder herunterfahren; physischer Zugang nur durch Berechtigte (z. B. abschließbare Räume, Diebstahlsicherungen wie Kensington-Locks). |     |
| 2. Datenträgerkontrolle     | Verhinderung unbefugten Lesens/Kopierens/Änderung/Löschens von Datenträgern         | Mitnahme nur genehmigter, verschlüsselter Datenträger; Regelungen zur Transport- und Aufbewahrungssicherheit.                                                                   |     |
| 3. Speicherkontrolle        | Verhinderung unbefugter Eingabe/Kenntnisnahme/Änderung/Löschung gespeicherter Daten | Vollverschlüsselung tragbarer Systeme (z. B. BitLocker/FileVault); Passwortschutz und automatische Sperre.                                                                      |     |
| 4. Benutzerkontrolle        | Verhinderung unbefugter Nutzung via Datenübertragung                                | VPN für Fernzugriff; Zugriffsregeln für fremde Netze/WLANs; Verbot ungesicherter Hotspots.                                                                                      |     |
| 5. Zugriffskontrolle        | Berechtigte nur auf umfasste Daten zugreifen                                        | Rollenbasierte Zugriffsrechte (RBAC) auf mobilen Geräten; Datenklassifizierung und Zugriffsprotokollierung.                                                                     |     |
| 6. Übertragungskontrolle    | Nachverfolgbarkeit von Übermittlungen                                               | Protokollierung von Datenübertragungen (z. B. via VPN-Logs); Audit-Trails für Zugriffe unterwegs​.                                                                              |     |
| 7. Eingabekontrolle         | Nachprüfbarkeit von Eingaben/Änderungen                                             | Logging von Änderungen (z. B. in Office-Dokumenten oder System-Logs); regelmäßige Synchronisation mit zentralem Server​.                                                        |     |
| 8. Transportkontrolle       | Schutz von Vertraulichkeit/Integrität bei Übermittlung/Transport                    | TLS/VPN für Übertragungen; physische Sicherung (z. B. verschlossene Taschen) und Verschlüsselung von Datenträgern​.                                                             |     |
| 9. Wiederherstellbarkeit    | Wiederherstellung im Störungsfall                                                   | Regelmäßige Datensicherungen (lokal + zentral); Synchronisation und Backup-Strategien mit mindestens einer Generation im Büro​.                                                 |     |
| 10. Zuverlässigkeit         | Verfügbarkeit aller Funktionen, Meldung von Fehlern                                 | Automatische Updates, Virenschutz und Monitoring-Tools; Meldepflicht für Störungen​.                                                                                            |     |
| 11. Datenintegrität         | Schutz vor Beschädigung durch Systemfehler                                          | Redundante Speicher, Prüfsummen und Integritätschecks bei Synchronisation​.                                                                                                     |     |
| 12. Auftragskontrolle       | Verarbeitung nur nach Weisungen des Auftraggebers                                   | Klare Richtlinien für mobile Mitarbeiter (z. B. Verbot fremder Systeme ohne Genehmigung); Schulungspflicht​.                                                                    |     |
| 13. Verfügbarkeitskontrolle | Schutz vor Zerstörung/Verlust                                                       | Verlustmeldung innerhalb Stunden; Fernlöschung/Lock-Funktionen (z. B. MDM-Systeme); Backup-Pflicht​.                                                                            |     |
| 14. Trennbarkeit            | Getrennte Verarbeitung unterschiedlicher Zwecke                                     | Datenisolierung durch Klassifizierung; separate Container/VPNs für sensible vs. normale Daten.                                                                                  |     |
